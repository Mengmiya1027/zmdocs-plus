# ZMdocs & 稚梦 · 随意写，随意看

{% quot 梦到什么写什么。不保证有用，不保证有趣，但保证都是真的。 %}

## 怎么来的

{% timeline %}
<!-- node 第一版 -->
愿Wish 想搭个网站。她搭了一个，稚梦看了一眼，说这颜色不对。
<!-- node 第二版 -->
她又搭了一个，稚梦看了一眼，说排版好挤。
<!-- node 第三版 -->
她搭了第三个，稚梦说这回看着还行……但是你要放什么内容？
<!-- node 就此定下 -->
愿Wish 沉默了一下，说：“嗯，随便写点吧。”于是就有了这个神奇的小网站。
<!-- node 现在 -->
前后搭了不知道多少遍，改了多少版，吵了多少次。稚梦嫌弃动画不够细节，愿Wish嫌弃要求太多。最后把电脑往桌上一拍——就这版了，不准再改了！稚梦说，行，反正也看习惯了。
{% endtimeline %}

## 现在这上面有什么

说实话，不太确定。

{% note color:green 技术笔记 有时候是技术笔记，因为愿Wish 碰到一个 bug 改了三小时，不能白改，得记下来。 %}
{% note color:purple 半夜的想法 有时候是半夜的奇怪想法，因为稚梦半夜睡不着，打开电脑敲了几行字就关机了。 %}

想到什么写什么，想不起来就空着。没有内容规划，没有更新计划。你看的时候有新的就是新的，没有就是还没梦到。

{% quot 不是没追求，是追求的恰恰就是这份不用刻意。 %}

## 就两个人

{% grid c:2 %}
<!-- cell -->
![愿Wish](/public/images/basic/avatar-mmy.jpg)
**愿Wish**：写代码的，负责把东西搭起来，逻辑自洽，能跑就行。
<!-- cell -->
![稚梦](/public/images/basic/avatar-zm2.png)
**稚梦**：负责挑刺的，嫌颜色不对、排版不好、语气太冷。然后改完又觉得第一版好像也行。最后两个人吵一架。最后改来改去，达成一个折中版本。
{% endgrid %}

两个人共用一张书桌，两把椅子。有时候写着写着就吵起来——一个说“代码能跑就行”，一个说“不好看就重写”。最后互相妥协，各退半步，成了现在你看到的样子。

{% quot 不完美，但两个人都勉强接受。 %}

## 关于这个名字

{% note 稚 稚，是出发时的样子。什么都不懂，什么都好奇，什么都想试试。代码写得稀碎也不怕人笑话，反正慢慢改就是了。 %}
{% note 梦 梦，是要去的地方。它不在眼前，但你知道它在。可能永远到不了，但往那个方向走，总比停在原地强。 %}

所以叫稚梦。

{% folding 听起来有点矫情？ %}
行吧，那就矫情。反正是自己的地方。

说起来，这俩名字听起来挺正经的，但其实起名的时候根本没想这么多。就是觉得“稚梦”俩字好听，就用了。后来被人问起来，才慢慢编出这套解释。
{% endfolding %}

## 最后

{% quot 如果你一路翻到了这里——谢谢，真的。 %}

{% blockquote %}
一个随缘更新的博客，有人从头看完了，这不是常有的事。

不用收藏，不用订阅，不用特意记住。以后什么时候想起来，点进来看一眼就行。

如果有新内容说明我们最近有想法。如果什么都没变说明这段时间在专心吃饭睡觉。

反正日子就是这样。写点代码，记点梦话，和另一个人吵吵架，偶尔改个版。

梦到什么写什么，写到哪里算哪里。
{% endblockquote %}

**——愿Wish & 稚梦 于某次改版后的平静期**
