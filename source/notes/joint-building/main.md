# 共建须知

一起造点东西吧？如果你对我们的作品感兴趣，并且想帮助我们一起建造blog，我们乐意和你一起，把这座数字小站打磨成我们共同喜欢的样子。

我们不需要你十项全能，只要你有一份好奇心——会写两行代码也好，擅长捕捉错别字也罢，或只是偶尔冒出个让人眼前一亮的好点子，都欢迎。

你可以来 GitHub 提 Pull Request，可以发邮件聊聊你的想法，也可以先在评论区留个脚印。我们不赶工期，只想在折腾代码和文字的间隙，遇见志趣相投的人。
