{% quot 运行ATB el:h2 %}

{% timeline %}
<!-- node 第 1 步 · 启动 -->
打开下载好的AllToolBox工具箱，双击“双击运行”，启动AllToolBox主程序
{% image /public/images/xtc/root/launchingATB.png 双击「双击运行」启动 AllToolBox 主程序 %}
{% note color:yellow 虽然工具箱能够自动安装驱动，但还是建议您务必在启动前完成驱动的安装！ %}
<!-- node 第 2 步 · 一键root -->
进入主界面后，会出现如下图所示的界面，这是工具箱的主菜单，使用鼠标左键双击`1.一键root`
{% image /public/images/xtc/root/ATBmain.png AllToolBox 主菜单，双击「1.一键root」 %}
<!-- node 第 3 步 · 下载 -->
等待下载部分必要文件
{% image /public/images/xtc/root/ATBdownloading.png 等待下载部分必要文件 %}
<!-- node 第 4 步 · 声明 -->
下载完成后会要求您同意《免责声明》。在仔细阅读并同意本声明后按两次{% kbd Enter↩︎ %}即可。
{% endtimeline %}

###### 请确认：
{% checkbox checked:true 我同意相关《免责声明》 %}

{% quot 断网操作 el:h2 %}

紧接着，工具箱会提醒我们拔出{% mark SIM卡 %}。拿出手表的取卡器，拆下手表的SIM卡，并关闭手表的{% mark WiFi %}和{% mark 数据流量 %}开关，然后按键盘上任意键即可。

{% note color:red 警告 务必在root前断开网络连接！由未跟随操作指引断网的行为带来的后果，将无法得到保证。（您的手表可能变砖、云控） %}

###### 请确认：
{% checkbox checked:true 手表已经按上述指引断网 %}
