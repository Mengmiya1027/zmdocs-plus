# 准备工作

在正式开始 root 之前，请先确认设备型号，并完成以下各项准备工作。

{% quot 适用范围 el:h2 %}

{% note color:red 本教程不适用于想要为手表解绑的用户。请勿使用ATB为手表解绑！ %}

所有搭载 {% mark Android 操作系统 %} 的小天才电话手表（{% mark Z12 %} 除外，如您使用的是这部分型号，那么请花钱找人帮忙，因为文件资源暂未公开）适用于本教程。

判断方法：打开手表 `设置` → `我的设备` → `本机信息`，向下滑动，如找到「{% mark 安卓版本 %}」字样，则说明您的手表符合要求，请继续阅读本教程。

{% note color:yellow 没有“安卓系统”？ 如没有找到，则说明您的手表是 RTOS 系统，请更换其他教程，并使用 [星河工具箱](https://milkyway.zh.kg/)。 %}

本章节{% mark color:red 不提供 %}[星河工具箱](https://milkyway.zh.kg/)的教程。如您需要使用，请更换其他教程。

{% quot 硬件准备 el:h2 %}

{% checkbox 一台搭载 Windows 10 及以上版本系统的电脑 %}
{% checkbox 一根数据线 %}
{% checkbox 您的手表 %}
{% checkbox 一把金属镊子或平头螺丝刀（仅限使用四点线的机型） %}

{% folding open:true color:cyan 如何选择数据线？ %}

{% grid bg:card c:2 %}
<!-- cell -->
**四点线** · {% mark Z8/Z8SNB %} 及以下

充电接口有 4 个金属触点，京东、淘宝、拼多多等平台均有售，价格通常在 10-20 元之间。
<!-- cell -->
**六点线** · {% mark Z7S、Z8A 及以上，Z10 及以下 %}

只有 2 个金属触点的机型，目前仅闲鱼有售，价格在 60 元左右。
<!-- cell -->
**卡槽线** · {% mark Z11 %} 系列

目前仅闲鱼有售，价格在 160 元以上。
<!-- cell -->
**六点线（判断）** · {% mark Z8A/Z9 及以上 %}

观察手表左侧充电口，中间两点颜色偏暗即为此类机型。
{% endgrid %}

{% quot 其他准备 el:h2 %}

1. 打开家长管理端 App，点击右下角的 `更多` → `手表系统升级` → `有新版本自动更新` → `关闭自动下载并安装升级包`。

2. 将 AllToolBox 工具解压缩到一个文件夹。

{% note color:red 请勿直接在压缩包内运行「双击运行.exe」！ %}

3. 备份数据。（列表可左右滑动）

| 数据                                 | 备份方式                                                                                            |
|--------------------------------------|-----------------------------------------------------------------------------------------------------|
| 聊天记录                             | 可截图留存                                                                                          |
| 微聊表情包                           | 可以发送到家长手机上或者自己信任的朋友的手表上。                                                    |
| 照片、视频                           | 可以通过夸克网盘、天才云等app备份，可以发送给家长或朋友，也可以在操作过程中由工具备份到您的电脑上。 |
| 微聊好友、天才星(积分)、已购买的表盘 | 不会被清空，这部分数据已被保存在小天才的服务器内，在完成root后连接网络时会自动恢复。                |

{% note color:green 准备好了吗？ 完成以上步骤后，您就可以开始 root 您的手表了。 %}
